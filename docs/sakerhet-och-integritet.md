# Säkerhet och integritet

Principerna beskrivs på övergripande nivå. Implementationen är privat.

- **Passiva tester.** Inga inloggningar, inga formulär och inga försök att kringgå skydd.
- **Begränsad räckvidd.** Bara den egna domänen skannas och skannern kan inte nå interna adresser.
- **Åtkomstkontroll.** Konton godkänns manuellt och rapporter visas bara för ägaren och administratören.
- **Missbruksskydd.** Antalet skanningar och anrop är begränsat.
- **Säkerhetshuvuden.** Hemsidan använder bland annat strikt innehållspolicy och krav på krypterad anslutning.
- **GDPR.** Data lagras i EU, bara nödvändiga uppgifter samlas in och gammal data raderas automatiskt.
- **Ansvarsfull rapportering.** Sårbarheter kan rapporteras enligt https://agentkoll.se/sakerhet.
